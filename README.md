# Diagnosticador Energético 2000

Programa de console em C++ para registrar o consumo de energia de quatro setores ao longo de cinco dias e exibir totais, classificações e resumo do período.

## Compilação

O código usa recursos de console do Windows; compile `diagnosticador-energetico.cpp` em um ambiente C++ para Windows.
